# Calculator Web Application

A simple interactive calculator developed using HTML, CSS, and JavaScript. This project provides a user-friendly interface for entering mathematical expressions and performing basic arithmetic calculations.

## Project Overview

This calculator was developed as part of my CodSoft internship practice to strengthen my understanding of front-end web development and JavaScript programming.

## Features

- Interactive calculator interface
- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (/)
- Parentheses support
- Percentage button
- Decimal number input
- Clear (C) functionality
- Calculation using the equals (=) button

## Technologies Used

- **HTML5** – Calculator structure and input elements
- **CSS3** – Calculator layout and styling
- **JavaScript** – Button interactions and calculation logic

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Ensure all project files remain in the same directory.
4. Open `indx.html` in your web browser.
5. Use the calculator buttons to enter and calculate mathematical expressions.

No additional installation is required.
